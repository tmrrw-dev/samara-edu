SAMARA EDU v1.8

Структура каталога:
1. Выбор направления.
2. Выбор курса.
3. Выбор семестра.
4. Предметы выбранного семестра отображаются отдельными вкладками.
5. Нажатие на вкладку предмета открывает область будущих видеоуроков и материалов.

В каталоге оставлены только те направления/профили, для которых в подключённом учебном плане есть хотя бы один распределённый предмет. Курсы и семестры без предметов также скрыты.

Данные предметов перенесены из загруженного пользователем PDF. Для профилей, которых нет в этом PDF, направления скрыты, а предметы не выдумывались. Видео и дополнительные материалы пока не добавлены — соответствующая область подготовлена для следующего этапа.

Запуск: откройте index.html в браузере.
