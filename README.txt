SAMARA EDU — первая рабочая версия прототипа

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в браузере (Chrome, Edge, Firefox).
3. Интернет нужен только для загрузки веб-шрифта; сам интерфейс работает локально.

ЧТО УЖЕ РАБОТАЕТ
- Каталог направлений Института информатики и кибернетики.
- Поиск по направлениям, профилям и дисциплинам.
- Переход от направления к дисциплинам и странице дисциплины.
- Разделы «Видеоуроки», «Конспекты», «Практика», «О дисциплине».
- Отметка уроков как пройденных и сохранение прогресса в localStorage.
- Избранное (в рамках текущего браузера).
- Адаптивная тёмная тема.

ВАЖНО О ДАННЫХ
Направления и профили взяты из опубликованного каталога Самарского университета:
https://www.ssau.ru/education/program
Страница института:
https://ssau.ru/info/struct/op/faculties/iime
Официальные сведения об образовательных программах:
https://ssau.ru/sveden/education/eduop

Список дисциплин в прототипе — демонстрационный пример для проверки навигации.
Перед публикацией его необходимо заменить на дисциплины из учебных планов нужного года набора и профиля.
Видео, PDF и задания пока не загружены: странички и разделы подготовлены для наполнения.

СЛЕДУЮЩИЙ ЭТАП
Подключить серверную часть и базу данных, чтобы контентом можно было управлять через защищённую админ-панель, а не редактировать файлы вручную.
